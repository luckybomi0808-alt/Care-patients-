# CARE SHIFT — 간호 시뮬레이션 웹 게임

## 소개
간호학 진로 탐구를 위한 선택형 교육용 웹 게임입니다. 환자의 말을 듣고 안전을 확보하며, 담당 간호사에게 관찰 내용을 보고하는 과정을 연습합니다.

## 실행 방법
1. `index.html` 파일을 다운로드합니다.
2. 파일을 휴대폰 또는 컴퓨터 브라우저에서 엽니다.
3. 인터넷 연결이나 별도 설치 없이 플레이할 수 있습니다.

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html`을 저장소의 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 및 `/(root)`를 지정한 뒤 저장합니다.
5. 잠시 기다리면 공개 웹 주소가 표시됩니다.

## 기술
- HTML: 화면 구조
- CSS: 디자인 및 모바일 반응형 레이아웃
- JavaScript: 선택지, 피드백, 점수, 진행 단계

## 안전 안내
이 프로젝트는 진로 탐구용 가상 사례이며 의료 교육이나 실제 응급처치를 대체하지 않습니다. 실제 환자에게 적용할 지침은 최신의 공신력 있는 교육 자료와 지도 교사의 검토를 거쳐야 합니다.
